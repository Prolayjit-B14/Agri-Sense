# AgriSense Pro v17.4.9: Industrial Agronomy Suite

An industrial-grade, deterministic agronomic advisory and IoT monitoring platform. AgriSense v17.4.9 is a high-fidelity diagnostic ecosystem that bridges real-time field telemetry with scientific crop suitability intelligence. Powered by **React 19**, **Vite**, and **Capacitor**, it delivers a production-grade advisory experience for professional agriculture.

---

## 🚀 Key Innovations (v17.4.9)

### ✨ "Crystal Smooth" Aesthetic
*   **Production-Grade UI**: A unified, high-fidelity design system featuring emerald gradients, crystalline transparency, and industrial-grade data density.
*   **Visual Parity**: Uniform 24px border-radius and 1rem geometric constraints across all modules (Soil, Weather, Storage, Water, Solar).
*   **Micro-Animations**: Fluid transitions powered by Framer Motion for a premium, responsive feel.

### 📊 Scientific Intelligence Suite
*   **21+ Diagnostic Charts**: Forensic-level visualization across five monitoring nodes.
*   **Dual-Line Correlation Engine**: Advanced visual linking of environmental variables to visualize cause-and-effect field health.
*   **Zero-Lag Stabilization**: Hardened Recharts implementation with locked Y-axis domains for flicker-free monitoring.

### 🛡️ Production Readiness
*   **Firebase Integration**: Secure Firestore telemetry and real-time UI handshaking with Sync Status indicators.
*   **Offline-First Watchdog**: Robust fail-safe logic ensuring data integrity during network fluctuations.
*   **Optimized Analytics**: 5-second telemetry sampling for high-resolution real-time monitoring.

## ⚙️ Installation & Build

1. **Clone & Install:**
   ```bash
   git clone https://github.com/Prolayjit-B14/Agri-Sense.git
   cd Agri-Sense
   npm install
   ```

2. **Development Mode:**
   ```bash
   npm run dev
   ```

3. **Production Android Build:**
   ```bash
   npm run production:sync
   cd android && ./gradlew assembleRelease
   ```
